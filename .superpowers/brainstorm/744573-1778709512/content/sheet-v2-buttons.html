LangGraph: ¿lo necesitamos?

Mantener single LLM call (actual)

  • 1 call por turno → 1 JSON estricto
  • State en Postgres + python state machine
  • ~600 LOC backend ya implementado
  • Coste ~$0.001/turno con gemini-flash
  • Provider-agnostic (Gemini / Claude / OpenAI / Fake)
  • Suficiente para 5 turnos + repair loop ya existente

LangGraph (deferir a v1.1+)

  • Útil si añadimos critic agent que revise synthesis
  • Útil para tool-use (search KB, re-pedir screenshot)
  • Útil para multi-actor (writer + reviewer)
  • Lock-in LangChain ecosystem
  • +coste 3-5x (multi-paso)
  • +complejidad: grafos, checkpoints, persistencia

Recomendación: single LLM call para v1.0.0. LangGraph entra cuando midiendo veamos que la calidad de synthesis es insuficiente o queremos tools.
