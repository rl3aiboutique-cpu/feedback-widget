# Stack agent-eyes + E2E del feedback-widget

## Contexto

Sesión de redesign chat-first del widget (ver [[2026-05-13_feedback-widget-v1-redesign]]). S1 done, S2 frontend pendiente. Para que el agente verifique el frontend del widget en navegador real durante dev + para tener cobertura E2E hacia V1.

## Decisión

Adoptar dos herramientas con responsabilidades separadas:

| Herramienta | Rol | Versión instalada |
|---|---|---|
| `agent-browser` (vercel-labs) | "ojos" del agente — exploración interactiva via accessibility tree refs (`@e1`, `@e2`) y screenshots anotadas | 0.27.0 global vía npm |
| `@playwright/test` | E2E tests escritos por humanos/agente, parte del suite del proyecto | 1.60.0 dev-dep |

## Ubicación

- `agent-browser`: binario global, fuera del repo. Chrome for Testing 148 en `~/.agent-browser/browsers/`.
- `@playwright/test`: dev-dep en `apps/sandbox-host/frontend/package.json`. Browsers en `~/.cache/ms-playwright/`.

## Por qué `apps/sandbox-host/frontend`

El sandbox-host monta el widget como en prod-like. E2E debe ejercitar el widget INTEGRADO en el host, no aislado. `packages/feedback-frontend` se mantiene puro como SDK publicable.

## Por qué ambos

- agent-browser ≠ reemplaza Playwright. Refs determinísticos + JSON output nativo lo hacen mejor para uso CLI del agente (exploratorio); Playwright sigue siendo el estándar para test suites mantenibles con codegen, traces, fixtures.
- Coexisten: agent-browser detecta el Chrome de Playwright si lo encuentra (no duplica downloads en otras máquinas).

## Permisos

`.claude/settings.local.json` allowlist:
- `Bash(agent-browser *)`
- `Bash(pnpm exec playwright *)`
- `Bash(pnpm playwright *)`
- `Bash(cd apps/sandbox-host/frontend && pnpm exec playwright *)`

## Pendientes

- Scaffold E2E suite en `apps/sandbox-host/frontend/tests/` cuando S2 frontend arranque (no antes — sin UI nueva no hay qué testear).
- CI: no entra en `.github/workflows/ci.yml` todavía. Sprint gates de V1 (`.claude/rules/v1-sprint-gates.md`) controlan cuándo Playwright pasa a required job.
- En Linux puede requerir `agent-browser install --with-deps` si fallan shared libs al primer launch.

## Alternativas descartadas

- Root `tests/e2e/` workspace nuevo — infra extra sin payoff inmediato.
- Playwright en `packages/feedback-frontend` — mezcla SDK publicable con dev infra.
